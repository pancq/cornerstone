## UI / 设计体系评估（第二轮，用户问"UI 设计怎么样"）

组队 engineering-ui-review（Archi + Cody + Tessa），对前端做设计体系+代码质量+测试评估。

### 关键发现
1. **设计体系成熟度 2/10**：四套配色同时共存——Ant Design(#1890ff)、Element Plus 默认(#409eff)、style.css Tailwind 系(#3b82f6)、legacy.css 飞书系(#3370ff)
2. token 形同虚设：style.css/legacy.css 的 token 全库几乎零外部引用，组件内硬编码 hex 880~945 处
3. Element Plus 主题零覆盖（无 sass、无 --el-color-primary 覆盖）→ 双蓝同屏
4. legacy.css 是活污染源（覆盖字号 16→14）；style.css 约 216 行因 App.vue scoped 提升特异性而失效
5. **3 处真实 UI 破损**：`.nav-tooltip` 等样式类未定义、骨架屏 `.loading` 类从不添加、`.global-language-switcher` 未定义
6. P0 安全：credentials 明文落 localStorage；loadState JSON.parse 无 try-catch 致全站白屏且不可恢复
7. fetchUser→refreshAccessToken 无限递归；两套 401 链路打架；router catch 死代码致过期跳 /403
8. 路由零懒加载（31 静态 import）；巨型组件（AlertsPage 1762 行等）
9. 测试 0%、无测试基建；aria-label 全库 0 处；无移动端适配
