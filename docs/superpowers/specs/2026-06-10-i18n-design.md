# 中英文切换功能设计文档

## 1. 概述

为 Cornerstone 网络管理系统添加中英文切换功能，支持用户在不同语言环境下的使用需求。

## 2. 功能需求

- **全部翻译**：包括所有页面、表单、按钮、提示消息、表格列名等
- **语言切换方式**：浏览器语言自动检测 + 手动切换按钮
- **持久化**：LocalStorage + 数据库（用户登录后同步到数据库）

## 3. 技术选型

| 项目 | 方案 | 说明 |
|------|------|------|
| **国际化库** | vue-i18n | Vue 3 官方推荐的国际化方案，与 Pinia 状态管理集成良好 |
| **语言文件格式** | JSON | 易于维护和协作 |
| **持久化** | LocalStorage + 数据库 | 用户已登录则同步到数据库，换设备保持偏好 |

## 4. 架构设计

### 4.1 目录结构

```
frontend/src/
├── locales/
│   ├── zh-CN.json      # 中文翻译
│   └── en-US.json      # 英文翻译
├── i18n/
│   └── index.ts        # i18n 配置
├── store/
│   └── locale.ts       # Pinia 状态管理
└── components/
    └── LanguageSwitcher.vue  # 语言切换组件
```

### 4.2 语言切换流程

```
用户首次访问
    ↓
检查 LocalStorage
    ↓
已有偏好？ → 是 → 直接应用
    ↓ 否
已登录？ → 是 → 从数据库获取偏好
    ↓ 否
浏览器语言检测（zh-CN / en-US）
    ↓
设置应用语言
```

## 5. 组件设计

### 5.1 LanguageSwitcher 组件

- **位置**：页面顶部导航栏，用户头像附近
- **样式**：下拉菜单，包含中文/English 选项
- **功能**：
  - 显示当前语言
  - 点击切换语言
  - 切换后立即生效
  - 持久化到 LocalStorage
  - 登录用户同步到数据库

### 5.2 Pinia Store (locale.ts)

- **状态**：
  - `locale`：当前语言（zh-CN / en-US）
  - `isInitialized`：是否已初始化
- **动作**：
  - `initialize()`：初始化语言
  - `setLocale(locale)`：设置语言
  - `syncToServer()`：同步到数据库（已登录用户）
- **getter**：
  - `currentLocale`：当前语言代码

## 7. API 设计

### 7.1 后端接口

```python
# 更新用户语言偏好
PUT /api/v1/users/me/settings
{
    "locale": "zh-CN" | "en-US"
}

# 获取用户语言偏好
GET /api/v1/users/me/settings
{
    "locale": "zh-CN" | "en-US"
}
```

### 7.2 前端 API 调用

```typescript
// 设置语言偏好
async function updateLocale(locale: string): Promise<void>

// 获取语言偏好
async function getLocale(): Promise<string>
```

## 8. 数据库设计

### 8.1 users 表新增字段

```sql
ALTER TABLE users ADD COLUMN locale VARCHAR(10) DEFAULT 'zh-CN';
```

## 9. 实现步骤

### 步骤 1：安装依赖

```bash
npm install vue-i18n
```

### 步骤 2：创建翻译文件

- 创建 `src/locales/zh-CN.json`
- 创建 `src/locales/en-US.json`
- 提取所有现有页面中的硬编码文本

### 步骤 3：配置 i18n

- 创建 `src/i18n/index.ts`
- 配置 vue-i18n 插件
- 设置默认语言

### 步骤 4：创建 Pinia Store

- 创建 `src/store/locale.ts`
- 实现语言初始化逻辑
- 实现语言切换逻辑
- 实现持久化逻辑

### 步骤 5：创建语言切换组件

- 创建 `src/components/LanguageSwitcher.vue`
- 实现下拉菜单
- 实现切换逻辑

### 步骤 6：集成到 App.vue

- 在顶部导航栏添加 LanguageSwitcher 组件
- 初始化语言设置

### 步骤 7：后端支持

- 在 users 表添加 locale 字段
- 创建用户设置 API
- 实现语言偏好同步

### 步骤 8：替换硬编码文本

- 逐个页面替换硬编码文本为 $t() 函数调用
- 确保所有用户可见文本都被翻译

## 11. 注意事项

- 翻译文件中避免使用占位符拼接，使用完整的句子
- 日期、时间、数字等使用 locales 参数格式化
- 考虑 RTL（从右到左）语言的扩展性（未来需求）
- API 返回的数据（如设备名称、IP）不翻译
- 错误消息保持与后端一致
