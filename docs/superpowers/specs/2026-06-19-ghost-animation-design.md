# 登录页幽灵角色交互动画设计文档

## 1. 概述

为登录页实现4个幽灵角色（橙色、紫色、黑色、黄色）的交互式动画系统，采用简洁克制的动效风格，保持专业感的同时提供友好的交互反馈。

## 2. 设计原则

- **微动效为主**：避免大幅度弹跳和夸张表情
- **线性过渡**：使用 `ease-out` 缓动，保持流畅但不夸张
- **响应式反馈**：输入时有轻微的点头、视线跟随等反馈
- **专业感**：动效幅度控制在最小有效范围内
- **60fps流畅度**：使用CSS transform和GPU加速

## 3. 角色定义

| 序号 | 颜色 | 名称 | 特点 |
|------|------|------|------|
| 1 | #FF6B35 | 橙色幽灵 | 领导者，动作幅度最大 |
| 2 | #9B59B6 | 紫色幽灵 | 跟随者，动作幅度中等 |
| 3 | #2C3E50 | 黑色幽灵 | 沉稳，动作幅度较小 |
| 4 | #F39C12 | 黄色幽灵 | 活泼，有独特的额外动作 |

## 4. 动画效果详细设计

### 4.1 页面加载动画

- **入场顺序**：橙色 → 紫色 → 黑色 → 黄色
- **入场方式**：从左侧滑入，带轻微过冲
- **入场延迟**：每个幽灵延迟0.15s
- **入场完成后**：上下呼吸浮动 ±2px，缓慢自然

### 4.2 全局鼠标跟随效果

- **眼睛跟随**：平滑跟随鼠标位置转动，范围限制在眼球内部
- **头部倾斜**：随眼睛转动方向做 ±3° 以内的微小倾斜
- **过渡效果**：线性过渡，无弹性回弹

### 4.3 用户名输入框交互

- **输入框聚焦时**：
  - 视线全部聚焦到输入框位置
  - 嘴巴轻微张开（宽度增加2px）
  - 身体轻微前倾（倾斜角度 ≤5°）

- **输入过程中**：
  - 眼睛跟随光标左右移动
  - 每输入/删除一个字符，同步做一次轻微点头（幅度 ≤3°）
  - 黄色幽灵额外做一次轻微上下蹦跳（幅度 ≤3px）

### 4.4 密码输入框交互

- **输入框聚焦时**：
  - 橙色幽灵看向左侧
  - 紫色幽灵看向斜上方
  - 黑色幽灵和黄色幽灵闭眼并微微转头背对输入框
  - 嘴巴变为闭合的小横线表情
  - 整体姿态略微后缩

- **密码明文/密文切换时**：
  - 显示密码（明文）：所有幽灵快速瞟一眼输入框（0.3s），然后转回回避状态
  - 隐藏密码（密文）：视线缓慢转回正常状态（0.5s过渡）

### 4.5 验证码输入框交互

- **输入框聚焦时**：
  - 视线聚焦到验证码输入框
  - 黄色幽灵眼睛缩小（模拟眯眼辨认）
  - 嘴巴变为小横线
  - 身体微微前倾

- **输入过程中**：
  - 眼睛跟随光标移动
  - 每输入一个字符，轻微点头一次（幅度 ≤3°）

### 4.6 登录按钮交互

- **点击按钮时**：
  - 视线转向按钮
  - 嘴巴变为期待的微笑表情
  - 身体轻微前倾

- **登录请求中**：
  - 嘴巴保持微笑
  - 身体缓慢上下浮动

- **登录成功时**：
  - 嘴巴张开
  - 轻微弹跳一次（幅度 ≤5px）
  - 随后恢复呼吸浮动状态

- **登录失败时**：
  - 嘴巴变为下垂的难过表情
  - 头部轻微左右摇晃（幅度 ≤3°，持续0.5s）
  - 随后恢复正常状态

## 5. 技术实现方案

### 5.1 架构设计

采用组件化架构，将动画逻辑与UI分离：

```
LoginPage.vue
├── GhostCharacter.vue (可复用的幽灵角色组件)
│   ├── character-body
│   ├── character-face
│   │   ├── eyes (包含瞳孔)
│   │   ├── mouth
│   │   └── blush (腮红)
│   └── character-shadow
└── AnimationController.ts (动画状态管理)
```

### 5.2 状态管理

使用Vue响应式系统管理动画状态：

```typescript
interface GhostState {
  x: number           // 水平位置
  y: number           // 垂直位置
  headRotation: number // 头部旋转角度
  bodyRotation: number // 身体旋转角度
  pupilX: number      // 瞳孔水平偏移
  pupilY: number      // 瞳孔垂直偏移
  mouthState: 'normal' | 'open' | 'smile' | 'sad' | 'surprised'
  eyeState: 'open' | 'closed' | 'squinting'
  isBouncing: boolean
  isBreathing: boolean
}
```

### 5.3 性能优化

- **GPU加速**：使用 `transform: translateZ(0)` 或 `will-change: transform`
- **节流处理**：鼠标移动事件做节流，避免性能消耗
- **CSS transitions**：优先使用CSS动画而非JS动画
- **投影优化**：鼠标悬停时投影柔和扩散

- ✅ 鼠标移动时眼睛平滑跟随，头部微小倾斜
- ✅ 用户名输入框聚焦时视线聚焦，输入时轻微点头

- ✅ 登录按钮点击、请求中、成功、失败各有相应动画

- ✅ 动效幅度克制，不影响登录页专业性
